About me

I’m Ashwin Rajesh, a visually impaired second-year B.Tech student in Computer Science and Engineering at IIIT Delhi, a FIDE-rated chess player and a three-time Delhi State Chess Champion for the Visually Impaired.

Chess taught me to plan several moves ahead and to stay calm when a position gets complicated. I bring the same approach to software: break the problem down, check every edge case, then build something dependable.

That is how my main project started. As a visually impaired player myself, I wanted blind and low-vision players to set up a Lichess position as easily as anyone else, so I built a screen-reader-friendly tool to do it. Projects

Accessible Chess Position Builder

Blind and visually impaired players can’t easily set up a position on Lichess by dragging pieces. This full-stack web app lets them enter which piece is on which square through a screen-reader-friendly form, then builds the board and opens it in Lichess.

  • Takes piece positions through a screen-reader-friendly form.
  • Validates them against chess rules and converts them into FEN notation plus a one-click Lichess analysis link.
  • Built on a Flask REST API with server-side validation for invalid squares, occupied squares, king adjacency and pawn placement. Clear error messages explain what is wrong and how to fix it.
  • Deployed with a separate frontend and backend, with CORS enabled.
